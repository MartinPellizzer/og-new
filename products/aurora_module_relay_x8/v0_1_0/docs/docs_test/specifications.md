# Specifications

## Specification 1

### Requirement

The Relay Module shall execute relay-output commands received from Core

### Specifications

The Relay Module must communicate with CORE via Modbus RTU protocol and RS485 standard. The Relay Module must execute only 0x04 commands on address zero-based 0x0000 (30001).

## Specification 2

### Requirement

The Relay Module shall provide Core output status
